Add preconditions, the checks that run before a chat input or context menu command, following `@sapphire/framework`. A `Precondition` piece in the new `preconditions` store implements `chatInputRun` and/or `contextMenuRun` and answers with `ok()` or `error()` (a `PreconditionError` for the piece); a piece with a `position` is global and runs for every command in ascending order of it. The new `preconditions` option of `Command.Options` lists the ones a command needs, by name, by name with a `context`, or as a `PreconditionFunction`. The first denial skips the command method and is emitted as `chatInputCommandDenied` or `contextMenuCommandDenied`. `AllFlowsPrecondition`, `PreconditionStore`, `runPreconditions` and the related types are exported, and `Identifiers` gets `PreconditionMissingChatInputHandler` and `PreconditionMissingContextMenuHandler`. Autocomplete is not checked, and there are no built-in preconditions, nested `AND`/`OR` arrays, or `Accepted` event.
